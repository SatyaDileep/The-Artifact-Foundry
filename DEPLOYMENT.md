# Deployment Runbook — Artifact Foundry

This runbook takes the project from a local checkout to a live, production site
on **Vercel** (app) + **Supabase** (database, auth, edge functions). Total time:
about 30–45 minutes the first time.

> **Prereqs**
> - Node 20+, the [Supabase CLI](https://supabase.com/docs/guides/cli), and a
>   GitHub account
> - A **Supabase** account (free tier is fine to start)
> - A **Groq** API key (free tier: https://console.groq.com)
> - A Google OAuth client (for curator sign-in)
>
> Embeddings for the RAG search are generated by Supabase's **free built-in
> model** (`gte-small` via `Supabase.ai`) — no embedding provider or extra key
> needed.

---

## 1. Push the code

The working tree currently contains the full Next.js rewrite (untracked) plus
deleted Flutter sources. Stage the project, commit, and push:

```bash
git add .
git commit -m "Next.js rewrite: learning-artifact platform with AI generation, RAG, and admin auth"
git push origin main
```

If the remote doesn't exist yet:

```bash
git remote add origin https://github.com/<you>/<repo>.git
git push -u origin main
```

## 2. Supabase project & schema

1. Create a project at https://supabase.com/dashboard — note the **Project URL**
   and **anon key** (Settings → API).
2. Open **SQL Editor** and run the entire contents of `supabase/schema.sql`.
   It is idempotent — safe to re-run.
3. Grant yourself curator access:

   ```sql
   INSERT INTO admin_users (email) VALUES ('you@example.com');
   ```

   (This is the allowlist used by Row Level Security. The same email must be in
   the `ADMIN_EMAILS` env var on Vercel — step 6.)

4. **Sanity check RLS:** in **Table Editor**, open `admin_users` — you should
   see your row. Try selecting it signed-out (anon) in the API docs — it should
   return nothing.

## 3. Google OAuth (curator sign-in)

1. Create an OAuth client at https://console.cloud.google.com/apis/credentials
   (Web application; add the redirect URI
   `https://<your-project-ref>.supabase.co/auth/v1/callback`).
2. In Supabase → **Authentication → Providers → Google**, paste the Client ID
   and Secret, and save.
3. Under **Authentication → URL Configuration**, set **Site URL** to your
   production URL (step 6) and add it + `http://localhost:3000` to
   **Redirect URLs**.

## 4. Deploy edge functions

```bash
npm i -g supabase   # if not installed
supabase login
supabase link --project-ref <your-project-ref>

supabase secrets set \
  GROQ_API_KEY=... \
  GROQ_MODEL=llama-3.3-70b-versatile \
  SUPADATA_API_KEY=...

supabase functions deploy generate-artifact
supabase functions deploy index-artifacts
supabase functions deploy ask
```

`supabase/config.toml` declares the JWT policy: `ask` is public
(`verify_jwt = false`), the other two require a signed-in curator.

## 5. Embeddings (nothing to configure)

Semantic search uses Supabase's **free built-in embedding model** (`gte-small`, 384 dims)
via `Supabase.ai.Session` inside the edge functions. There is no API key, no
provider setup, and no dashboard configuration — just run **Reindex search**
in the admin once content exists. If indexing ever fails, `ask` automatically
falls back to keyword search so the site keeps working.

## 6. Vercel app

1. Import the GitHub repo at https://vercel.com/new
2. Framework preset: **Next.js** (auto-detected). Build command: `next build`.
3. Add environment variables (from `.env.local.example`):

   | Variable | Value |
   | --- | --- |
   | `NEXT_PUBLIC_SUPABASE_URL` | `https://<project-ref>.supabase.co` |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon key |
   | `SUPABASE_SERVICE_ROLE_KEY` | service role key (server-only) |
   | `ADMIN_EMAILS` | `you@example.com` (same as step 2) |
   | `NEXT_PUBLIC_SITE_URL` | `https://<your-app>.vercel.app` |
   | `NEXT_PUBLIC_DEMO_MODE` | **unset** (or `false`) — never `true` in prod |

4. Deploy. Subsequent pushes to `main` auto-deploy.

## 7. First content & index

1. Visit `/admin`, sign in with Google, and confirm you land on the dashboard
   (if you're not the allowlisted email you'll be bounced to `/`).
2. **Create** an artifact: paste a YouTube URL or a transcript → **Generate
   with AI** → review → **Publish**. Publishing auto-indexes that artifact.
3. **Manage** tab → **Reindex search** to embed everything at once.
4. Visit `/ask` and try: *"What is the difference between being rich and being
   wealthy?"* — you should get a cited answer.

## 8. Launch checklist

- [ ] `https://<app>/` loads; hero, paths, categories render; Inspect Me works
- [ ] `/role/product-manager` shows curated sources with working links
- [ ] `/artifact/<slug>` shows quotes, flipcards, moments; source link opens
- [ ] `/ask` answers with citations and source cards
- [ ] `/admin` — non-admin Google account is redirected home
- [ ] `/sitemap.xml` and `/robots.txt` resolve; artifact pages contain JSON-LD
- [ ] Supabase **Authentication → Users** shows your signed-in curator
- [ ] **Table Editor**: `content` rows exist; `artifact_chunks` populated after
      Reindex; drafts are invisible on the public feed

## 9. Make it yours

- Update the brand name/tagline in `src/app/layout.tsx` (metadata) and
  `src/components/Header.tsx`
- Add more career paths: insert into `roles` + `role_sources` (see
  `supabase/schema.sql` for the shape)
- Point the domain in Vercel → Domains and set `NEXT_PUBLIC_SITE_URL` to it;
  update the Google OAuth redirect if needed

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| "Sign in failed" on Google | Check OAuth Client ID/Secret and redirect URI (step 3) |
| Admin redirects to `/` after sign-in | `ADMIN_EMAILS` (Vercel) must contain the exact email you inserted into `admin_users` |
| Generate returns "Transcript is required" | Provide a transcript or a YouTube URL + set `SUPADATA_API_KEY` |
| Ask answers from keyword search only | Run **Reindex search** in `/admin` so chunks get embedded (vector mode) |
| Reindex reports embedding failures | Confirm the function deployed (step 4) and content has transcripts/quotes; re-run |
| Public feed shows nothing | Confirm `is_published = true` on rows; drafts are intentionally hidden |
